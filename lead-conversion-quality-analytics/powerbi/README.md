# Lead Conversion & Quality Analytics — Power BI

Open `LeadConversionQualityAnalytics.pbip` in Power BI Desktop to inspect the report and semantic-model source. The PBIP/PBIR/TMDL format keeps page definitions, visuals, measures, relationships, and queries reviewable in source control.

The privacy-safe lead table and analytical exports required by the model are included under `..\data\`. The original source file and legacy PBIX binary are intentionally excluded from this portfolio folder. The published report is available from the link in the root README.

The four report pages cover the executive overview, trend evidence, lead-quality drivers, and opportunity scenarios.
